# 🌱 EcoLoop – Small Actions. Big Impact.

### A Flutter-Based Sustainable Marketplace for Reusable & Upcycled Products

EcoLoop is a cross-platform mobile application built with **Flutter** that empowers individuals to buy, sell, donate, and exchange reusable items while promoting sustainable living. The platform connects users, artists, and eco-conscious communities to reduce waste, encourage upcycling, and support a circular economy.

Designed with a clean, modern, and user-friendly interface, EcoLoop makes sustainable choices simple and accessible from anywhere.

---

# 📖 About the Project

Every year, millions of reusable items are discarded despite still having value. EcoLoop aims to reduce unnecessary waste by providing a mobile platform where users can easily give unwanted items a second life.

Users can upload reusable products, donate items, exchange goods, or purchase affordable second-hand products. Artists can source reusable materials, transform them into creative products, and showcase their work through dedicated artist profiles.

By encouraging reuse, refurbishment, and responsible consumption, EcoLoop helps build a smarter and greener future.

# 👥 User Roles

| User Type | Role | Responsibilities |
|------------|------|------------------|
| User | Primary User | Register, upload reusable items, buy, sell, donate, exchange products, manage wishlist, earn Eco Points, and track environmental impact. |
| Artist | Creator | Register as an artist, purchase reusable items, showcase creative work, manage portfolio, sell upcycled products, and accept custom orders. |
| Guest | Visitor | Browse products, explore categories, view artist profiles, and search items before creating an account. |
